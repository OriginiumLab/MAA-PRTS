# debug —— 运行日志

## 用途

只有运行日志 `app.log`：每行一条 `[HH:MM:SS] 内容`，记录启动信息、端口、
接口异常堆栈、任务结果。超过 2 MB 自动改名为 `app.log.1` 并重新开始。

排查问题时优先看这个文件：

- 启动失败的 Python 报错会写在这里
- `/api/*` 的异常会带 traceback 最后三行
- 写入 MAA 的每一步也会打到任务日志（界面上能看，但只有这里留档）

## 注意

- 整个目录随时可以删，程序下次启动会重建
- 日志不含 token（token 是密文存在各账号 json 的 `skd` 段与旧版
  `config/tokens.json`），但可能含路径和账号昵称，贴给别人看前自己过一眼
- 旧版日志在 `config/app.log`，升级后首次启动会自动挪到这里
