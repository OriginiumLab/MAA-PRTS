# MAA-PRTS 使用说明

## 一、怎么跑起来

1. 把整个 MAA-PRTS 文件夹解压到任意可写目录
   建议 D 盘或桌面，不要放 `C:\Program Files`（会因权限写不了配置）
2. 双击 `MAA-PRTS.exe`
3. 首次启动会出现引导：
   - 选择 MAA 根目录（就是含 `MAA.exe` 的那个文件夹）
   - 粘贴森空岛 token

   两步都填好就能用了；暂时没有 MAA 也可以先点「稍后设置」。

> 注意：`_internal` 文件夹必须和 `MAA-PRTS.exe` 放在一起，不要只把 exe 拖出来，
> 否则会提示缺少 DLL 或直接闪退。

## 二、森空岛 token 怎么拿

1. 浏览器打开 <https://www.skland.com/> 并登录自己的账号
2. 按 F12 打开开发者工具，切到 Network（网络）标签，刷新页面
3. 在请求列表里找一个发往 `zonai.skland.com` 的请求，
   点开后在请求头里找到 `token`，把整段值复制出来
4. token 会过期，失效了重新取一次即可（界面「添加账号」粘新的）

## 三、功能速览

- 左侧列表切换账号，一点即切
- 顶部四个数字：干员数 / 精二 / 满级 / 缺卡；点「缺卡」看还差哪些干员
- 搜索框输关卡代号（TL-10）、活动（act55side 或中文名）、系列（TR-）
- 搜索结果按你的练度分档：可直接用 / 需借一个干员 / 需练度 / 缺太多
- 右侧「作业集」收集要跑的作业，拖动手柄可以调顺序，顺序就是 MAA 执行顺序
- 单个作业点复制即可拿到 `maa://` 代码，自己在 MAA 里粘贴
- 多个作业点「写入 MAA 并重启」：会自动关 MAA → 备份配置 → 写作业列表 → 重启

## 四、数据存在哪

| 文件 | 内容 |
|---|---|
| `config\<昵称> <服务器>.json` | 每个角色生成的练度配置，你填的 token 也密文存在这份文件里（DPAPI 加密，仅本机当前 Windows 用户可解） |
| `config\tokens.json` | 旧版本迁移留下的密文 token 库（只读兜底，全部账号重新同步后可删） |
| `config\settings.json` | MAA 路径、默认配置名等设置 |
| `debug\app.log` | 运行日志（出问题先看这个，超过 2 MB 自动轮转） |

全部只在本文件夹内，不会上传。删掉文件夹就彻底清除。

token 密文绑定本机：换电脑把账号 JSON 拷过去，练度数据还能看，但里面的
token 解不开，到新机器重新粘贴一次 token 即可。

写入 MAA 时会在 MAA 的 config 目录留一份配置备份
（`gui.new.json.bak-app-时间戳`），只保留最近 2 份，多余的自动删掉。

## 五、常见问题

1. **双击没反应 / 闪退**
   - 确认 `_internal` 文件夹完整存在
   - 确认解压目录可写（换个非系统盘目录试试）
2. **提示找不到 MAA**
   - 设置里重新选 MAA 根目录，要选到含 `MAA.exe` 的那一层
3. **写入后 MAA 里没有作业**
   - 先确认写入时选的配置名就是 MAA 里正在用的配置
   - 写入需要 MAA 完全退出，手动关掉再试一次更稳
4. **杀毒软件报毒**
   - PyInstaller 打包的程序偶发误报，添加到信任列表即可
5. **同步账号失败**
   - token 过期，重新按上面第二步取一个
