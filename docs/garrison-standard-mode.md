# 卫戍协议：独立模拟（规程等级 1）策略与补丁说明

本文档说明 `resources/garrison/patches.json` 中新增的 **独立模拟（标准模式 · 规程等级 1，14 回合，60 个单人策略全刷）** 策略补丁与通用稳定性修复（均针对 `medal-farm-v1.1.4` 核心，在 `v1.1.5` / `v1.1.7` 上因 `find` 规则不命中会自动安全跳过，且 **100% 不影响极速模拟模式**）。

---

## 1. 实测表现

在规程等级 1（精准 / 奥术 / 协防体系，覆盖除联机专属 `band_protect` 外的全部 60 个单人策略）连续实战测试中：

- 连续跑通 **30 / 60** 策略金章（单局目标 6 胜 / 通关）；
- 策略定型后最近 8 场完整对局：**7 胜 1 负（胜率 87.5%）**；
- 平均单局耗时约 **26 分钟**（19.9–29.8 分钟），成型后自动速通跳店；
- 支持凌晨 **04:00 每日同步/热更重启** 自动关闭公告/配给/语音下载弹窗、标题页重登并点击卫戍主页「继续模拟 / 继续独立模拟」无缝续打。

## 2. 核心策略设计（仅 `mode === "standard"` 生效）

1. **阶梯上本与卡 5 级（Lv5 Cap）**
   - 节奏：`R1:1 → R2-3:2 → R4-5:3 → R6-7:4 → R8+:5`，永不升 6 级（标准模式 6 级费过高、5 级商店即可稳定出 4–6 阶终结者与三连）。
   - 禁止 R6 → R7 连跳空升本；R8/R9 升 Lv5 前需场上/备战席满 5 名真实干员，避免空城升本暴毙。
   - **上本优先，三连锁住**：在计划升本回合若可升本先升本，升本后由 `ga()` 自动冻结买不起的 `2+1` / `1+2` 三连卡，下回合直接合成；升本前余 1–2 金且商店无目标卡时执行 `_preUp` 白嫖刷新。
   - **资金不结转**：标准模式每回合资金清零，余钱 ≥ 3 金积极 D 牌找三连与核心，绝不留钱浪费。

2. **精准 / 奥术 / 协防 阵容体系与前排保障**
   - 盟约权重：`精准 300 / 奥术 150 / 协防干员 60`，核心叠层池：`冻河 / 空弦 / 黑键 / 霍尔海雅 / 迷迭香 / 圣聆初雪 / 初雪`。
   - 精准与协防按**不同名干员数**计数；满 3 后仍放行已持同名卡（追三连，如第 2 张空弦）、`奥术` 双词条（`霍尔海雅`）、核心叠层、终结者与 5 阶以上高阶卡。
   - 前期（R1–R8）特赦并提权 `雪猎`、`承曦格雷伊`（+180），保证前期平稳过渡不掉血。
   - 中期（R5+）缺地面前排时优先补强力地面（`青枳 / 余 / 罗比菈塔 / 涤火杰西卡`，买不起自动锁店）；零地面且无未识别干员时兜底真坦克（`block ≥ 2` 或 `坚守 / 不屈 / 协防干员 / 自回 / 治疗`，明确排除 `乌有` 等 1 挡脆皮）。

3. **严格「场上 8 人满再卖人」与中后期战力部署**
   - R7+ 回合开始清理非奥术/精准 1–2 阶低阶卡：仅在 `ye()` 读盘后且同时满足 **场上 ≥ 8 人** 且 **总真实干员 > 8** 时触发，优先卖备战席、跳过精锐干员、最多卖到剩 8 人即止。
   - 锁店差 1 金卖工具人同样要求 R7+ 且场上满 8 人。
   - 部署阶段 `focusBonds` 纳入 `协防干员`，R10+（或 R9 已 Lv5）切换为 `defense` 战力部署，防止 `艾雅法拉 / Mon3tr / 夜莺 / 塞雷娅` 坐板凳。

4. **真盟约成型速通跳店**
   - 满足以下全部条件且无决策弹窗时跳过商店直接开战：
     - 商店等级 `≥ 5`；
     - 场上真盟约达标（`3 精准` / `3 奥术` / `2 协防干员` 至少达成 2 项）；
     - 场上不同名终结者 `≥ 2`（`塔露拉 / 维伊 / 艾雅法拉 / 逻各斯 / 圣聆初雪 / 克莱门莎`，以及 **精锐三连空弦**）。

## 3. 通用 Bug 修复（标准 / 极速均可受益）

- **备战席黑名单修复 (`fix-removed-slot-blacklist-v114`)**：卖出备战格干员后若新购干员落入同一格（`source === "shop"`），原代码因只认 `source === "panel"` 导致新干员被长期拉黑无法部署；现改为仅当该格确为空位时保留黑名单。
- **信标自毁装备防护 (`fix-beacon-debuff-v114`)**：除卡名匹配 `信标` 外，按描述匹配 `销毁携带干员 / 目标干员和本装备销毁` 标记为 `debuff`，防止 OCR 错字销毁主力。
- **商店刷新抗 OCR 抖动 (`fix-shop-refresh-resilience-v114`)**：避免单帧漏扫 `^刷新$` 直接抛错弃掉整回合剩余金币，补截 2 帧重试并设置收尾复核次数上限。
- **凌晨 04:00 每日重启与弹窗全自动恢复 (`std-fastskip-and-4am-maa-recovery-v114`)**：参考正版 MAA `StartUp / CloseAnnos` 坐标与流程，覆盖热更同步、资源释放等待、语音下载取消、公告/签到/配给关闭、标题页 `START` 重登、主界面防抖、卫戍主页「继续模拟 / 继续独立模拟」续打，并记录 `[4am]` 诊断日志。

## 4. 必要干员与练度建议（独立模拟 · 精准/奥术/协防体系）

> 卫戍协议中**只有编入干员池的干员才会被抓到**，策略核心依赖 **精准 + 奥术 + 协防 + 优质前排**。若缺少以下关键干员，建议在「预备干员 / 助战」或常规池中优先配齐。

### A. 核心必备（强烈建议全部拥有并精二）

| 定位 | 干员 | 阶数 | 盟约 | 作用说明 |
|---|---|---|---|---|
| **核心终结者** | **艾雅法拉** | 4 阶 | 奥术 | 4 阶即出、成型极快，高台清杂与打 BOSS 核心，速通终结者之一 |
| **核心终结者** | **逻各斯** | 6 阶 | 奥术 | 后期最强法伤终结者，5 级店即可刷出，显著提升 R12–R14 胜率 |
| **核心终结者** | **圣聆初雪** | 5 阶 | 奥术 | 兼具奥术叠层与终结者定位，5 阶稳定刷出 |
| **核心终结者** | **维伊** / **塔露拉** | 4 / 6 阶 | 奥术（塔露拉兼协防） | 补足终结者数量，塔露拉同时占奥术+协防两格极其灵活 |
| **精准核心/三连终结者** | **空弦** | 3 阶 | 精准 | 精准体系灵魂叠层手；**三连精锐后直接视作终结者**，大幅提前成型 |
| **双核心桥梁** | **霍尔海雅** | 4 阶 | 奥术 + 精准 | 同时推进精准与奥术两条核心盟约，满 3 精准仍优先抓取 |
| **协防核心（至少 2–3 位）** | **塞雷娅** / **夜莺** / **初雪** / **Mon3tr** | 3–5 阶 | 协防干员 | 触发 2 协防保后排不暴毙；**塞雷娅**兼优质地面阻挡与奶，**夜莺**防法伤 BOSS 极关键 |

### B. 前中期稳血与优质前排（强烈推荐配齐）

| 定位 | 干员 | 阶数 | 作用说明 |
|---|---|---|---|
| **优质地面前排（4 选 2+）** | **青枳**、**余**、**罗比菈塔**、**涤火杰西卡** | 3–4 阶 | R5+ 缺地面时最高优先级抓取（买不起会自动锁店），扛线稳血核心 |
| **前期精准核心** | **灰喉**（1 阶）、**雪猎**（2 阶）、**承曦格雷伊**（2 阶） | 1–2 阶 | R1–R8 提权特赦，低费迅速凑齐 3 精准稳住前期血线 |
| **前期奥术核心** | **卡达**（1 阶）、**Miss.Christine**（2 阶） | 1–2 阶 | R1–R3 凑奥术与叠层，廉价过渡 |
| **中后期精准叠层** | **黑键**（4 阶）、**迷迭香**（5 阶）、**鸿雪**（5 阶） | 4–5 阶 | 补足后期精准输出与叠层上限 |

### C. 兜底与注意事项

- **备选地面兜底**：若上述 4 位优质地面未全，可备 **车尔尼 / 深巡 / 海沫 / 瑕光** 等 3 阶及以上、阻挡 ≥ 2 或带坚守/自回的前排干员。
- **避免过度依赖 1 挡近战**：脚本已自动屏蔽 `乌有` 等 1 挡脆皮作为零地面兜底，防止中期漏怪。
- **练度建议**：核心终结者（艾雅法拉 / 逻各斯 / 圣聆初雪 / 空弦）与协防（塞雷娅 / 夜莺 / Mon3tr）建议 **精二 60+、核心技能 7 级以上**（专三最佳）；1–2 阶过渡卡（灰喉 / 卡达 / 雪猎 / 承曦格雷伊）精一满级即可胜任规程等级 1。
